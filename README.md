# Production Scheduling Automation

Automated production scheduling system using optimization algorithms to maximize manufacturing efficiency and minimize downtime.

## 🎯 Project Overview

This project automates production scheduling decisions using constraint programming and optimization algorithms, helping manufacturers reduce lead times, minimize setup costs, and improve resource utilization.

## 🛠️ Technologies Used

- **Python 3.x**
- **Pandas & NumPy** — Data manipulation
- **OR-Tools** — Constraint programming and optimization
- **PuLP** — Linear programming
- **Matplotlib & Plotly** — Gantt charts and visualizations

## 📊 Key Features

- Job shop scheduling with constraint satisfaction
- Resource allocation optimization
- Multi-objective optimization (minimize makespan, maximize utilization)
- Gantt chart visualization
- Real-time schedule updates and conflict resolution
